What happened?

You are trying to calculate the average of an empty list. Because the list has no items, the count is 0. Math doesn't allow dividing by zero!

How to fix it

def calculate_average(numbers):
    if not numbers:
        return 0
    total = sum(numbers)
    count = len(numbers)
    return total / count

Pro Tip

Always check your boundaries! When writing functions that take collections (like lists or arrays), form a habit of asking: "What happens if this is empty?" This prevents unexpected crashes in production.
